# PersonaForge AI

AI-powered personal branding platform.

## Current starter version

- Flask application
- MySQL database schema
- Basic homepage
- Starter dashboard
- Modular routes/services structure
- Environment configuration

## Planned modules

1. Authentication
2. AI Career Interview
3. Structured User Profile
4. AI Content Generation
5. BrandMind AI
6. Dynamic Portfolio Generator
7. Live Preview
8. Resume/Portfolio Export

## Setup

```bash
python -m venv venv
```

Windows:

```bash
venv\Scripts\activate
```

Install packages:

```bash
pip install -r requirements.txt
```

Create the MySQL database by running:

```text
database/schema.sql
```

Then run:

```bash
python app.py
```

Open:

```text
http://127.0.0.1:5000
```

Do not put real API keys or passwords into GitHub.
